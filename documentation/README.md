# Project Documentation

This folder contains living documentation maintained by the Cursor agent. It is updated after every interaction to keep a record of development progress.

## Contents

| File | Purpose |
|------|---------|
| [challenges.md](./challenges.md) | Challenges encountered during development and how they were solved |
| [bugs.md](./bugs.md) | Bugs found and their fixes |
| [project-state.md](./project-state.md) | Current state of the project, architecture, and known limitations |
| [last-edit.md](./last-edit.md) | Summary of the most recent edit/interaction |

## Update Policy

The Cursor agent should update these files after every significant interaction:

- **challenges.md** — When a non-trivial challenge is encountered and resolved
- **bugs.md** — When a bug is identified and fixed
- **project-state.md** — When the project structure, features, or architecture changes
- **last-edit.md** — After every interaction (brief summary of what was done)
